# 직물 구조로 성능을 미리 맞히는 AI — 연구 계획 브리핑

PM: 한양대학교 의류학과 스마트텍스타일연구실(담당 교수 배지현, [연구실 소개](https://fashion.hanyang.ac.kr/-19))의 직물 태·마찰전기 AI 예측 과제 연구 계획을 섬유 조직 캐릭터들이 브리핑하는 정적 웹 문서입니다. 기준일 2026-11-17.

## 1차년도 방법 정의 (2026-11-17 확정)

> 실측 직물 데이터의 패턴(결합분포)을 학습하는 생성 모델로 새 직물을 만들고, 그 직물의 전기적 특성을 연속값(회귀형 출력)으로 예측한다.

- **실측** — 섬유직물의 주요 특성(실·조직·밀도·두께·평량·표면·압축·굽힘 등)과 전기적 특성(마찰전기 전압·전류·전하밀도)을 함께 계측. 전기적 특성은 엄격한 정답(라벨)이 아니라 직물 특성 중 하나
- **학습** — 비지도. 지금까지 모은 직물들의 패턴을 생성 모델로 학습
- **출력** — 새 직물과 그 전기 특성의 연속값(회귀형 출력) + 범위. 회귀(지도) 모델은 비교 기준
- **검증** — 생성 직물 일부를 실제로 만들어 측정 오차 범위 안에서 맞는지 확인
- **이미지** — 섬유 이미지는 2차년도 이후 활용

근거 문헌과 위험·검증 방법은 `method_review.html`에 있습니다.

## 캐릭터 — 섬유 조직

| 캐릭터 | 조직 | 역할 |
|---|---|---|
| 평직이 | 평직(Plain) — 날실·씨실이 한 올씩 번갈아 오르내림 | 보고 |
| 능직이 | 능직(Twill) — 교차점이 밀려 사선 무늬 | 질문 |
| 편직이 | 편직(Knit) — 실 고리를 엮음 | 기록 |
| 부직이 | 부직포(Nonwoven) — 섬유를 바로 얽어 붙임 | 수정·보완 요청 접수 |

그림은 `src/chars.py`가 표정별 SVG로 직접 만들어 페이지에 넣습니다(외부 그림 팩 없음).

## 문서 구성

| 쪽 | 파일 | 내용 |
|---|---|---|
| INDEX | `index.html` | 1차년도 방향, SUMMARY(실측 데이터 3D 6단계 + 관계 보기: 변수 2개 × Y 단면, 나머지 17개 고정, 2차 다항 모델), 전체 연구 계획 정리, 스테이지 현황, 검토 결과·부직이 요청 모음, 지식 색인·내려받기 |
| 1차년도 연구 방법 검토 | `method_review.html` | 방법 정의, 학습 방식과 출력, 문헌 검토, 위험과 대응, 모의실험, 제안 절차 6단계, 검토 문헌 15편 |
| 연차별 연구계획 | `plan_years.html` | 5년 로드맵 (1차년도 방향 반영, 3~5차년도는 예정) |
| 전체 스테이지 및 FLOW | `stages.html` | 흐름도, 일정, S0~S6 카드 |
| S0 착수·자료 정리 | `stage_0_kickoff.html` | 데이터 현황, 결정 질문 10개 |
| S1 파일럿 탐색 분석 | `stage_1_explore.html` | PCA, 장비 간 일치도 |
| S2 샘플 확충·전기 특성 실측 | `stage_2_data.html` | 기록 항목, 실험계획 |
| S3 직물 패턴 학습 (생성 모델) | `stage_3_model.html` | 생성 모델과 비교 기준 회귀, 과적합·누수 실험, 평가 기준 |
| S4 새 직물 생성·전기 특성 예측 | `stage_4_sim2real.html` | 생성·연속값 예측·품질 검사 (파일 이름은 이전 그대로) |
| S5 생성 직물 검증 | `stage_5_tribo.html` | 후보 선정, 전향 검증 (파일 이름은 이전 그대로) |
| S6 측정 장치 개선 (예정) | `stage_6_device.html` | 정해진 것과 예정인 것 |
| 이미지 데이터 분석 (2차년도 이후) | `image_data.html` | 실습용 이미지 140장 진단과 보완사항, 사진이 벡터가 되기까지(이전 SUMMARY) |
| 작성 가이드 | `data_guide.html` | 가상 섬유 데이터 작성 규칙, 양식, 점검표 |
| 참고문헌 | `references.html` | 장비·마찰전기·시뮬레이션·모델·방법 검토·데이터 품질 문헌 |

각 쪽은 자체 완결 HTML입니다(스크립트·그림 내장). 검토 표시와 부직이 요청은 보는 사람의 브라우저(localStorage)에만 저장됩니다.

## 폴더

```
*.html                 게시용 페이지 14개
src/                   빌드 소스 (build_pages.py가 진입점, chars.py가 캐릭터, pages_method.py가 방법 검토 쪽, summary3d.py가 3D SUMMARY)
analysis/image_data/   이미지 데이터 분석 스크립트와 결과 (features.csv 등)
meta/                  표지·이미지 프롬프트(이전 기록), 지식 색인 등록부
```

## 다시 빌드하기

```bash
python3 src/build_pages.py        # 저장소 루트에 html 14개를 다시 씀
python3 src/chars.py out_dir      # 캐릭터 SVG만 따로 보고 싶을 때
```

이미지 특징 재계산: `python3 analysis/image_data/feat.py <fabric_dataset 폴더>` → `clf.py`

원자료(연구계획서, 데이터셋 엑셀, 이미지 데이터셋 원본)는 이 저장소에 넣지 않았습니다.
